# Demo artwork

Small public YouTube thumbnail fixtures for the six existing sample occurrences.
Downloaded from `https://i.ytimg.com/vi/<videoID>/hqdefault.jpg` on 2026-11-05.
These are thumbnails, not media streams. They let the synthetic UI demo and
offline rendering tests display real artwork without an account or API request.
No real library was used. Normal library artwork uses validated thumbnail URLs.
