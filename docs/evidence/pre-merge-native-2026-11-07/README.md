## Debug evidence and cleanup

Symptoms: the new oversized-header transport test initially timed out. Hypotheses tested: broken accounting versus delayed synthetic URLProtocol callback delivery. Evidence: other limits rejected correctly; instrumented callback entry was absent for the header-only case until timeout. Confirmed cause: this URLProtocol simulator withholds header delivery until body/EOF. Fix applied: the fixture emits EOF and an independent direct-callback test verifies immediate header rejection and task cancellation before body bytes. Both transports were observed against the same simulator; no real-wire claim follows. Instrumentation removed: all `[DEBUG-apibudget]` prints and their temporary output logs, with no server or environment toggle left. Final uninstrumented transport tests pass. Residual risk: real decompression, provider/network faults and OS buffering are not simulated by this test.

The first new recovery-test payload omitted mandatory nullable DTO fields; that fixture was corrected. The first media-state assertion compared before the replacement's legitimate progress update; the regression now waits for that update, then verifies that the retired session produces no publication. Neither test correction relaxed the production gates.
